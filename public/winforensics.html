Features

Professional forensics tools, no bloat

Everything you need for Windows incident response in a single binary.

REG

Registry & SAM Analysis

Parse Windows registry hives and SAM. Extract user activity, installed programs, and persistence mechanisms. Android ADB/APK forensics included.

REC

Integrity & ADS Scanning

Authenticode integrity checks plus alternate-data-stream discovery. Surfaces unsigned, tampered, and stream-hidden binaries.

TL

Timeline Correlation

Correlate events across registry, execution artifacts and logs into one reviewable timeline. Sentinel mode keeps watching continuously.

EV

Quarantine & WORM Evidence

VirusTotal hash lookups, quarantine with restore, and a removable-media kit mode backed by a write-once evidence store.

MFT

Execution Artifacts

Prefetch, Amcache and ShimCache parsing for what actually ran on the box, plus memory inspection.

LOG

Event Log & Beaconing

EVTX and PowerShell script-block logs, plus live connection inspection with beaconing detection. Exports JSON, HTML and STIX 2.1.

Usage

Point and click, or drive it from a shell

The download is the GUI build. The same engine ships as winforensics-pro.exe for scripted use. Both prompt for UAC elevation, and some scanners need the LocalSystem agent installed by the MSI.

# Full forensic scan — every scanner group
winforensics-pro.exe full-scan --output .\reports

# Quick pass — volatile data + registry only
winforensics-pro.exe quick-scan

# Activate your license on this machine
winforensics-pro.exe activate WFP-XXXX-XXXX-XXXX

# Review and roll back quarantine
winforensics-pro.exe quarantine-list
winforensics-pro.exe quarantine-restore

# Android: enumerate and acquire over ADB
winforensics-pro.exe android-devices
winforensics-pro.exe android-acquire --output .\evidence

# Or just launch the GUI
winforensics-pro-gui.exe
