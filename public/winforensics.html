Features

What it checks

The same kinds of checks a professional investigator would run after a break-in, in one app you can run yourself.

REG

What’s installed, and who’s been here

Reads Windows’ own records to list user accounts, installed programs, and anything set to start itself up behind your back. Can check a plugged-in Android phone too.
For the pros: registry hives, SAM, persistence, ADB/APK.

REC

Tampered and hidden files

Spots programs that have been altered, aren’t signed by a real publisher, or are tucked away where Windows doesn’t normally show them.
For the pros: Authenticode, alternate data streams.

TL

One timeline of what happened

Pulls everything it finds into a single, in-order timeline so you can see what happened and when. Watch mode keeps an eye on things after the scan, too.
For the pros: cross-source event correlation, Sentinel mode.

EV

Lock away bad files (with undo)

Checks suspicious files against 70+ antivirus scanners at once, moves bad ones somewhere they can’t run, and lets you put them back if it guessed wrong. Can also run from a USB stick and save findings so they can’t be changed later.
For the pros: VirusTotal hash lookup, quarantine/restore, WORM evidence store.

MFT

What actually ran

Windows quietly keeps notes on every program that runs. WinForensics reads them, so a program that deleted itself still leaves a trail. Also looks at what’s running right now.
For the pros: Prefetch, Amcache, ShimCache, memory inspection.

LOG

Is something phoning home?

Reads Windows’ event logs and watches your internet connections for malware that checks in with its owner on a schedule. Save the results as a web page or hand them to an IT pro.
For the pros: EVTX, PowerShell script-block logs, beaconing detection; JSON, HTML, STIX 2.1 export.

Usage

Click a button, or type a command

Most people just open the app and click Scan. Windows will ask for permission when it starts — that’s normal, it needs administrator access to look everywhere. If you’d rather type commands or automate it, the installer also includes winforensics-pro.exe for the command line:

# Full forensic scan — every scanner group
winforensics-pro.exe full-scan --output .\reports

# Quick pass — volatile data + registry only
winforensics-pro.exe quick-scan

# Activate your license on this machine
winforensics-pro.exe activate WFP-XXXX-XXXX-XXXX

# Review and roll back quarantine
winforensics-pro.exe quarantine-list
winforensics-pro.exe quarantine-restore

# Android: enumerate and acquire over ADB
winforensics-pro.exe android-devices
winforensics-pro.exe android-acquire --output .\evidence

# Or just launch the GUI
winforensics-pro-gui.exe
