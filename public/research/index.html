Full audit of our from-scratch browser engine in Rust. 240 findings total, twelve with a security impact: page-controlled crashes, markup injection, viewer DoS, weak key derivation, and an agent policy that failed open. All fixed in v0.11.0.

My security gate’s safest verdict was reserved for its worst input

A researcher reported RCE in SassyMCP via SSH ProxyCommand injection. The named filter was never a filter. The real hole was that our command blocklist treated quoted strings as data — and SSH treats them as commands. Five tools, one shared gate, all vulnerable.
